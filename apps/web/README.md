# @qayd/web

The **web app** for QAYD — the browser-facing surface of the AI Financial
Operating System. Next.js 15 (App Router) · React 19 · TypeScript (strict).

## Role in the monorepo

- This app renders the UI and runs light server logic in Next.js Route
  Handlers / Server Components.
- **It holds no database credentials.** It never talks to Postgres directly.
- All business data flows through the Laravel API at `/api/v1`, consumed via the
  typed **`@qayd/sdk`** workspace package (never a raw `fetch` to the backend).

Polyglot siblings live alongside it: `apps/api` (Laravel/PHP, Composer) and
`apps/ai` (FastAPI/Python, uv). This app is part of the pnpm workspace; the
lockfile is at the repo root.

## Delivered in Sprint 1

- **App shell** — App-Router route groups split the **public/auth** area from the **authenticated**
  area behind an auth-gate, with a sidebar, topbar, company switcher, and light/dark theme.
- **Internationalization** — EN + AR, including full **RTL** for Arabic.
- **Auth screens** — login, register, email verification, and select/switch company, plus a
  **create-company onboarding wizard** — all wired to the Laravel API through `@qayd/sdk`.

| Route     | Kind          | Purpose                                                       |
| --------- | ------------- | ------------------------------------------------------------ |
| `/health` | Route Handler | Liveness probe → `{ "status": "ok", "service": "qayd-web" }` |

The API base URL is read from `NEXT_PUBLIC_API_BASE_URL` (see `.env.example`; defaults to
`http://localhost:8000/api/v1`).

## Local development

Run from the repo root so pnpm resolves the workspace:

```bash
pnpm install                 # installs the workspace; lockfile at repo root
pnpm --filter web run dev    # dev server on http://localhost:3000
```

Then open http://localhost:3000 and http://localhost:3000/health.

## Quality gates

All commands are run through pnpm's workspace filter from the repo root (the shared
`packages/*` are built first so `web`'s workspace imports resolve):

```bash
pnpm -r --filter "./packages/*" run build   # build the workspace packages web imports (incl. @qayd/sdk)
pnpm --filter web run lint                  # ESLint (flat config, eslint-config-next)
pnpm --filter web run typecheck             # tsc --noEmit (strict)
pnpm --filter web run test                  # Vitest (jsdom + Testing Library)
pnpm --filter web run i18n:check            # EN/AR message-catalogue parity
pnpm --filter web run build                 # next build (production)
```

All must be green. `next-env.d.ts` is generated by Next on `dev`/`build`
and is intentionally gitignored.
